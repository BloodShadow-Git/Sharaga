# Ячейка памяти
Основой ячейки памяти ПК является бит, а минимально адресуемая область байт
$$1111\ 1111_2 = FF_{16} = 255_{10}$$
**Слово** - совокупность нескольких байт, которую процессор обрабатывает как единое целое
$1111\ 1111\ 1111\ 1111_2 = FFFF_{16} = 65535_{10}$ - для 16 бит
$1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1111_2 = FFFF\ FFFF_{16} = 4\ 294\ 967\ 295_{10}$ - для 32 бит
Ячейка начиная с байта увеличивается на 2: 1, 2, 4, 8, 16
# Числа в памяти ПК
**Тип данных** - характеристика данных, определяющая диапазон их значений
## Безнаковые числа
Хранят только без знаковые чисела
$100_{10} = 1100100_2 = 64_{16}$
$100_{10} = 0110\ 0100_2 = 64_{16}$ - минималка
$100_{10} = 0000\ 0000\ 0110\ 0100 = 0064_{16}$ - для 2х битной системы
## Знаковые числа
Хранят число и его знак
Преобразование:
1. В двоичную: $|-100| = 100_{10} = 110\ 0100_2$
2. Добавили 0 до необходимого размера: $0110\ 0100_2$
3. Инвертируем: $0110\ 0100_2 = 1001\ 1011_2$
4. Добавить единицу: $1001\ 1011_2 + 1_2 = 1001\ 1100_2$

**-100**
16 и 32
$|-100| = 100_{10} = 110\ 0100_2$
16:
$0000\ 0000\ 0110\ 0100_2$
$1111\ 1111\ 1001\ 1011_2$
$1111\ 1111\ 1001\ 1011_2 + 1_2 = 1111\ 1111\ 1001\ 1100_2 = FF9C_{16}$
32:
$0000\ 0000\ 0000\ 0000\ 0000\ 0000\ 0110\ 0100_2$
$1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1001\ 1011_2$
$1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1001\ 1011_2 + 1_2 = 1111\ 1111\ 1111\ 1111\ 1111\ 1111\ 1001\ 1100_2 = FFFF\ FFAF_{16}$

**-1000**
16
$|-1000| = 1000_{10} = 11\ 1110\ 1000$
16:
$0000\ 0011\ 1110\ 1000_2$
$1111\ 1100\ 0001\ 0111_2$
$1111\ 1100\ 0001\ 0111_2 + 1_2 = 1111\ 1100\ 0001\ 1000_2 = FC18_{16}$
