По стандарту IEEE 754-2008 вещественные числа представлены: $X = \pm m * q^{\pm p}$
$m$ - мантисса числа
$q$ - основание системы счисления
$p$ - порядок
Особые числа:
- 0
$[0]_{бит\ знака}[0000\ 0000]_{смещённый\ порядок}[000\ 0000\ 0000\ 0000\ 0000\ 0000]_{мантисса\ 2} = 0000\ 0000_{16}$ - обычный 0
$[1]_{бит\ знака}[0000\ 0000]_{смещённый\ порядок}[000\ 0000\ 0000\ 0000\ 0000\ 0000]_{мантисса\ 2} = 0000\ 0000_{16}$ - отрицательный 0
- Бесконечность
$[0]_{бит\ знака}[1111\ 1111]_{смещённый\ порядок}[000\ 0000\ 0000\ 0000\ 0000\ 0000]_{мантисса\ 2} = 7F80\ 0000_{16}$ - обычная бесконечность
$[1]_{бит\ знака}[1111\ 1111]_{смещённый\ порядок}[000\ 0000\ 0000\ 0000\ 0000\ 0000]_{мантисса\ 2} = 0000\ 0000_{16}$ - отрицательная бесконечность
- NaN "Not a number" - "Не число"
$[X]_{бит\ знака}[1111\ 1111]_{смещённый\ порядок}[XXX\ XXXX\ XXXX\ XXXX\ XXXX\ XXXX]_{мантисса\ 2}$
- Денормализованные числа
$[X]_{бит\ знака}[0000\ 0000]_{смещённый\ порядок}[XXX\ XXXX\ XXXX\ XXXX\ XXXX\ XXXX]_{мантисса\ 2}$
