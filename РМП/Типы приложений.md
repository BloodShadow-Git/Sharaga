# Почему они разные
Основные причины:
- Скорость и стоимость разработки
- Производительность
- Охват платформ
- Доступ к возможностям телефона
- Команда и её навыки

Типы:
- Нативные
- Веб
- Гибридные
- Кроссплатформенные

# Нативные приложения
**Нативные приложения** - приложение созданное под одну платформу на её родном языке и с помощью её инструментов

**+**:
- Скорость
- Полный доступ
- "Родной" внешний вид
- Полноценная работа с магазином

**-**:
- Код под каждую платформу
- Дороже и дольше
- Нужны специалисты
- Два и более проекта на платформу

# Веб-приложения
**Веб-приложения** - приложения построенные на базе веб технологии
**PWA** - продвинутое веб-приложение, которое ведёт себя почти как обычное приложение

**+**:
- Один код на всё
- Не нужно устанавливать
- Мгновенное обновления
- Дешёво и быстро

**-**:
- Ограничения доступа
- Требуется интернет
- Ниже производительность
- Сложнее распространять в магазинах приложений

# Гибридные приложения
**Гибридные приложения** - веб-приложение в коробке нативного приложения
**Web-View** - скрытое окно браузера для отображения веб контента

**+**:
- Один код на все платформы
- Можно публиковать в магазинах приложений
- Есть частичный доступ к железу
- Подходит для разработчиков сайтов

**-**:
- Наличие прослойки в виде WebView
- Инородный интерфейс
- Тяжёлые задачи выполняются заметно дольше
- Проблемы с анимацией

> [!tip] Примечание
> Веб - без упаковки, а гибрид с

# Кроссплатформенные приложения
**Кроссплатформенные приложения** - приложения, которые написали 1 раз и на множество платформ

**Главные инструменты**:
- Flutter (Dart - Google)
- React Native (JS - Meta)
- Kotlin Multiplatform (Kotlin - JetBrains)

**+**:
- Один код на всё
- Скорость близкая к нативу
- Приложение почти "родное"
- Публикуется во всех магазинах

**-**:
- Зависимость от инструмента
- Сложные задачи всё равно требует нативного кода
- Требуется изучить фреймворк и его особенности
- Мало специалистов по технологиям

# Сравнение типов приложений
| Критерий | Нативные | Веб / PWA | Гибридные | Кросс­платформенные |
| --- | --- | --- | --- | --- |
| Технологии | Kotlin/Swift | HTML, CSS, JS | HTML, CSS, JS + оболочка | Dart, JS, Kotlin |
| Производительность | Высокая | Ниже | Ниже | Близка к нативной |
| Доступ к «железу» | Полный | Ограничен | Частичный | Широкий |
| Один код на все платформы| Нет | Да | Да | В основном да |
| Установка из магазина | Да | Обычно нет | Да | Да |
| Скорость обновления | Через магазин | Мгновенно | Через магазин | Через магазин |
| Стоимость/сроки | Выше | Ниже | Ниже | Средняя |
| Лучше всего для… | Игр, банков, «тяжёлых» задач | Простых информационных сервисов | Быстрого выпуска простого приложения | Выхода сразу на 2 платформы |

> [!tip] Примечание
> Кроссплатформа - 1 код, много платформ
> Мультиплатформа - 1 логика, много кода под каждую платформу
