# Основные понятия:
- ОС *Операционная система* - программный код управляющий ресурсами устройства и позволяет запускать другие программы
- Программа - набор инструкций и данных
- Компилятор и интерпритатор
- Клиент и сервер
- API - программный слой для приложений
# Что изучает
Разработку приложений для мобильных платформ
Мобильное приложение - программа, созданная для мобильного устройства

 # Мобильная платформа
**Мобильная платформа** - платформа шире чем ОС. Включает ОС, SDK и NDK и SDK магазина приложений
Платформы:
- Android
- iOS
- HarmonyOS (Huawei)
- KaiOS и т.д.
# Сравнение Android и iOS

| Разработчик | Google | Apple |
| --- | --- | --- |
| Открытость | AOSP | Закрыто |
| Устройства | Множество | Только Apple |
| Основной язык | Kotlin (Java) | Swift (Objective-C) |
| IDE | Android Studio | XCode |
| Основной магазин | Google Play | App Store |
| Доля рынка | ~72% | ~28% |
| Вероятность покупки приложения | Ниже | Выше |
| Разнообразие устройств | Высокое | Низкое |

# Фрагментация
**Фрагментация** - ситуация, при которой одновременно работают различные устройства
**Адаптивность** - возможность приложения подстраиватся под устройство на котором оно работает
