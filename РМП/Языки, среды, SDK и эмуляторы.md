# Языки программирования
**Приложение** - код на некотором [[#Языки программирования|ЯП]]
## Языки для Android
**Kotlin** - современный [[#Языки программирования|ЯП]] для "нативной" разработки под Android. Разработан JetBrains. Рекомендуемый для новых проектов. Сам из себя представляет обёртку над **Java**, а точнее работает на JVM
**Java** - старый язык для Android, использовался до 2017-2019. Разработан Oracle
## Языки для iOS
**Swift** - современный [[#Языки программирования|ЯП]] для техники Apple. Создан ими же
**Objective-C** - старый [[#Языки программирования|ЯП]] до **Swift**, тоже создан Apple под их ОС. Очень похож на C++, но в данный момент [[#Языки программирования|ЯП]] считается мёртвый
## Языки для кроссплатформенной разработки
**Dart** — язык фреймворка Flutter, Оба разработаны Google.
**JavaScript / TypeScript** — языки фреймворка React Native (Meta), а также веб- и гибридных приложений.
**Kotlin** — используется не только для нативного Android, но и в Kotlin Multiplatform для общей логики на разных платформах.

# IDE
**IDE** - программа, объединяющая набор инструментов
**Android Studio** - на базе IntelliJ IDEA (JetBrains) для разработки под Android. Актуальный "Quail"
**XCode** - только на MacOS и для разработки на **[[#Языки для iOS|Swift]]** и **[[#Языки для iOS|Objective-C]]**
**IntelliJ IDEA** - среда от JetBrains, используется в основном для Kotlin Multiplatform
**VS Code** - IDE от Microsoft, открытая версия Visual Studio (MacOS, Windows), кроссплатформенная на базе electron. Для поддержки языков требуются плагины
# SDK
**SDK** - набор инструментов, библиотек для создания ПО под определённую платформу
Состав:
- Компилятор и средства сборки
- Библиотеки и API
- Эмулятор
- Отладчик
- Документация и примеры

> [!tip] Виды API
> - **Web API** - сетевые запросы и ответы
> - **Device API** - системные команды для взаимодействия с железом устройства
> - **API в составе SDK** - обёртка над **Device API**, переводит инструкции от [[#Языки программирования|ЯП]] проекта или самого SDK в вызов **Device API**

# Android SDK
Состав:
- **SDK Platform** - файлы под конкретную версию ОС (Android 16, 15 и т.п.)
- **SDK Tools** - служебные программы (SDK Manager, AVD и т.п.)
- **Platform Tools** - инструменты для передачи данных
- **Build Tools** - инструменты сборки (Gradle и т.п.)
- **Emulator** - эмулятор android
- **Библиотеки** - готовые шаблоны кода от Google

**Уровень API** - число обозначающую версию API системы, а как следствие её возможности. С Android 4.4W (для умных часов) в июне 2014 года, а для телефонов с API 21 ноября 2014 с выходом Android 5 Lollipop, перешли на номер **API Level** привязан к номеру версии ОС как: ${Версия\_Android} + 20 = API\_Level$. Также версии ниже 20 прекратили свою поддержку в сервисах Google Play

# Эмуляторы и симуляторы
**AVD (Android Virtual Device)** - виртуальное устройство Android, конфигурируемое под каждую задачу
- Эмулятор - воспроизведение **железа**
- Симулятор - воспроизведение **поведения**
