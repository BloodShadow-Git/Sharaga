# Понятие полнотекстового поиска
**Полнотекстового поиска** - технология поиска документов или данных по всему их содержимому, а не только по названию, дате или другим метаданным
Система обычно ищет совпадения в:
- Наименованиях и описаниях
- Комментариях и характеристиках
- Текстах документов
- Дополнительных реквизитах
- Представлениях объектов

# Точный поиск и поиск по части строки
**Точный поиск**:
- Кода
- Номера документа
- Идентификатора

Пример: `ГДЕ Номенклатра.Артикул = &Артикул`
**Поиск фрагмента строки**
Пример:
```
ГДЕ Номенклатура.Наименование ПОДОБНО &Шаблон
&Шаблон = "%принтер%"
```

# Ограничения обычного поиска
Обычный поиск работает с конкретными полями. Чтобы искать по нескольким реквизитам, приходится объединять условия
# Полнотекстовый поиск
Ключевые возможности:
- Поиск по словам и словоформам
- Работа с большим объёмами текста
- Поисковые выражения
- Оценка степени соответствия
- Отсутствие необходимости вручную объединять множество условий

# Полнотекстовый индекс
Полнотекстовый индекс - специальная структура данных, которая позволяет быстро находить объекты по словам и фрагментам текста внутри больших объёмов текста

# Производительность и безопасность
Важно контролировать:
- Размер индекса и свободные место
- Нагрузку при массовой загрузке
- Скорость записи и проведения документов
- Актуальность результатов
- Количество отображаемых объектов
